## 3. Detailed Verification of Technical Invariants

### 3.1 Framework Separation
- CrewAI is strictly utilized for strategic decomposition (`RequirementAnalysis`), coordination, and delivery auditing.
- Google ADK is strictly utilized for execution tasks (`GoogleADKCoderAgent`, `GoogleADKTestGeneratorAgent`, `GoogleADKDebuggerAgent`, `GoogleADKRepositoryRAGAgent`).
- Communication across framework boundaries occurs exclusively via signed `A2AEnvelope` data structures.

### 3.2 State Synchronization & Non-Repudiation
- The `SharedBlackboard` executes state mutations under `threading.RLock()`.
- Every transition emits a monotonic version update ($v_0 \to v_N$) and atomic JSON disk checkpointing.
- The `ProvenanceTracker` records a SHA-256 Merkle chain linking requirements to final code diffs.

### 3.3 Security & Least Privilege
- Code containing forbidden syscalls (`os.system`, `subprocess`, `eval`, `exec`) is blocked by `ASTSafetyScanner`.
- Direct pushes to protected branches (`main`, `master`, `develop`) are hard-blocked by `GitManager`.
- Remote publishing requires explicit human gatekeeper approval and valid RBAC permissions.
